# Protocol: _1978_ - Game Design Documentation


> [!Note]
> 
> This game is under in development by **The Protocol Team members.**




### 1) Genre

* 2D Horror Platformer

* Strategy and Puzzle

### 2) Elevator Pitch

*	A 2D action puzzle game where you try to reach the final level by destroying waves of enemies coming at you.

### 3) Core Loop

* Collect + Reach to final boss

* Using some items to keep moving.

### 4) Controls
* WASD Player Controllers
  
* F button for torch
  
* E button to enter certain areas, places
  
### 5) Win/Loss Conditions

**I.**	**Win Scenarios:** The player eliminates all kinds of enemies that come their way and reaches the finale, achieving their goal.

============================================================================

**II.**	**Loss Scenarios:** As the player progresses, waves of enemies give damage and kill them. The player dies while fighting the final boss. The game restarts from where it left off.

### 6) Art Style

* A Pixel Art Game.
